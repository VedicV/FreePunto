# Changelog

## v0.3.0

- **Підтримка чату та полів вводу в Antigravity IDE та VS Code**:
  - Розширено розпізнавання поверхонь введення (`isConfirmedEditorSurface`): тепер будь-яке сфокусоване редаговане поле (`AXTextArea`, `AXTextField`, `AXComboBox`, `AXSearchField` або `isEditable`) в середовищі IDE автоматично вважається валідним. Усунуто блокування чату Antigravity/VS Code, панелі пошуку та полів повідомлень через нестандартні локалі чи плейсхолдери.
  - Додано апаратну затримку 20 мс у `sendKeyboardShortcut` між `keyDown` та `keyUp`: черга подій Electron/Chromium тепер стабільно реєструє синтетичні шорткати (`Option+Shift+Left`, `Cmd+C`, `Cmd+V`).
  - Додано `isEquivalentFocusElement`: захист від хибної втрати контексту фокусу при внутрішньому оновленні посилань на обгортки AX-елементів у Blink/Electron.
- **Виправлено роботу в Google Chrome на вебсайтах**:
  - Оптимізовано читання цілі: усунено зайвий «сліпий» виклик копіювання при невиділеному тексті, що прибрало паузу 400 мс і зберегло вміст буфера обміну.
  - Усунено повторний виклик `copySelection()` у фазі `prepare` для `copiedSelection`, що запобігає скиданню виділення на вебсторінках перед вставкою.
  - Пом'якшено перевірку `snapshotIsFresh`: нестабільність атрибута `AXSelectedTextRange` для DOM-елементів на вебсторінках Chromium більше не призводить до помилкового скасування заміни.
- **Повноцінна заміна виділеного тексту в терміналах**:
  - У термінальних емуляторах (VS Code Terminal, Antigravity Terminal, macOS Terminal.app) виділення мишкою є суто візуальним — шел (zsh/bash) про нього не знає, тому звичайний `Cmd+V` дописував текст у кінець рядка. Тепер при виділенні однорядкового фрагмента (до 120 символів) FreePunto автоматично надсилає точну кількість `Backspace`, витираючи оригінальне слово з промпту перед `Cmd+V`.
  - Розширено документацію щодо терміналів: технічне пояснення ескейп-коду `2D` при натисканні `Shift+Left Arrow`, використання режиму доступності `Option+F2` в IDE для читання промпту без мишки, а також переваги ZLE-віджета `freepunto.zsh`.
- **Очищення та оптимізація CI**:
  - У CI-пайплайні GitHub Actions прибрано запуск застарілих локальних UI-тестів, залишено швидку перевірку збирання релізного бінарника (`swift build -c release`).

## v0.2.2

- **Виправлено роботу в інтегрованих терміналах IDE (VS Code, Cursor, Antigravity)**:
  - Сувора валідація активного рядка промпту через `terminalPromptLastWord` — виключено помилкові читання виводу консолі (логів, помилок, списків файлів) та голих промптів без введеної команди.
  - При неможливості надійно довести активний промпт застосунок безпечно відмовляється (`beep`), без паразитного надсилання клавіш.
  - Для інтегрованого термінала заміна слова виконується строго через `Backspace` ровно `wordLength` разів та `Cmd+V` (без використання деструктивного `Ctrl+W` чи `Cmd+C`).
  - Видалено небезпечні кеші та фоллбеки (`recentConvertedText`, `lastTerminalElement`, `lastTerminalConversionTime`), що призводили до пошкодження попередніх команд та тексту з інших панелей.
- **Виправлено взаємодію з Firefox**:
  - Стратегія `browserEditableCmdCFirst` буквально починається з `Cmd+C`.
  - Повністю відключено нестабільні виклики `AXSelectedTextRange` та прямий запис AX для контентних полів Gecko.
  - Введено статус `.deliveredUnconfirmedAX`: якщо Firefox не оновив AX-атрибути синхронно після вставки, ложне повідомлення про помилку не відображається.
  - Збільшено затримку утримання транзитного буфера обміну до 150 мс перед його відновленням.
- **Покращено кругове послідовне перемикання (EN -> RU -> UA -> EN)**:
  - Цикл продовжується виключно тоді, коли реально прочитаний текст збігається з результатом попередньої конверсії (`textAfterConversion`).
  - Додано автоматичний пропуск ідентичних замін (наприклад, `git` -> `пше` -> пропуск однакового UA `пше` -> повернення в EN `git`).
- **Підтримка позначення тестових збірок**:
  - Автоматичне маркування версії у меню та ховер-підказці (`тестова версія` / `[TEST]`) при наявності суфіксів (`-test`, `-beta`, `-dev`) або прапорця `IS_TEST_BUILD=1`.

## v0.2.1

- Усунено причину зависання системи при відкликанні дозволів під час роботи програми: `HotKeyController` більше не намагається примусово перезапускати перехоплювач подій при отриманні `tapDisabledByUserInput`.
- Додано автоматизований скрипт встановлення та оновлення `scripts/install_or_update.sh`.
- Додано скрипт `Install or Update FreePunto.command` у DMG для безпечного оновлення в 1 клік (з автоматичним завершенням старого процесу та очищенням дозволів).
- Додано швидкий перехід до налаштувань Доступності та Моніторингу вводу у вікні діагностики дозволів.

## v0.1.2

- Виправлено Firefox-сценарій без явного виділення: браузер більше не використовує Accessibility range для пошуку попереднього слова, бо Firefox може повертати неправильну позицію.
- Для браузерів попереднє слово вибирається клавіатурним fallback у реальному активному полі.
- Явне виділення в браузерах читається через pasteboard без обов'язкового Accessibility-підтвердження, щоб Firefox не відкидав коректно скопійований текст.

- Перетворення розкладки EN/RU/UA.
