# FreePunto v0.1.4

## Українською

Технічний реліз для Firefox-сценарію без явного виділення.

### Що змінено

- Firefox більше не використовує Accessibility range для пошуку попереднього слова.
- Для браузерів попереднє слово вибирається клавіатурним fallback у реальному активному полі.
- Явне виділення в браузерах приймається з pasteboard без обов'язкового Accessibility-підтвердження.
- Це прибирає випадок, коли замість останнього слова виділявся фрагмент попереднього слова.

### Завантаження

Завантажте `FreePunto-0.1.4.dmg` з assets цього релізу.

## English

Technical release for Firefox when there is no explicit text selection.

### Changed

- Firefox no longer uses Accessibility ranges to find the previous word.
- Browsers use the keyboard fallback in the real active field for previous-word selection.
- Explicit browser selections are accepted from the pasteboard without requiring Accessibility confirmation.
- This avoids selecting a fragment of the preceding word instead of the word before the cursor.
