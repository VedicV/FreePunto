# Ручна перевірка отримання і заміни тексту

Дата перевірки: __________
Версія / build FreePunto: __________
macOS: __________
Перевірив: __________

Цей файл потрібен, щоб зафіксувати поточний стан після безпечних змін у логіці отримання тексту. Мета перевірки - не довести ідеальну політику, а побачити, що робочі сценарії не зламано.

Статуси:

- `OK` - працює як очікується.
- `FAIL` - не працює або псує текст.
- `SKIP` - застосунок або умови недоступні.
- `RISK` - працює нестабільно або потребує повторної перевірки.

## Перед перевіркою

- Запустити один і той самий зібраний `.app`, не пересобирати між тестами без потреби.
- Переконатися, що FreePunto має Accessibility/Input Monitoring дозволи.
- Увімкнути потрібні системні розкладки EN/RU/UA.
- Після кожної помилки перевірити `~/Desktop/freepunto.log`.
