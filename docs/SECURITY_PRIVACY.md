# Безпека та приватність

Останнє оновлення: 2026-09-07 (Версія 0.3.0)

## Позиція щодо безпеки

FreePunto розроблено як безпечна, автономна й локальна альтернатива Punto Switcher. Головна мета — виключити будь-яку можливість витоку конфіденційних даних, спостереження за користувачем чи перехоплення конфіденційної інформації.

Застосунок працює **виключно за явною командою користувача** (натискання гарячої клавіші або одиночного `Control`), не веде прихованого фонового аналізу та не виконує несанкціонованої автокорекції.

---

## Ключові принципи

- **0% мережевої активності**: застосунок на 100% офлайновий.
- **Жодної телеметрії**: відсутні трекери, аналітика чи відправка звітів про помилки на зовнішні сервери.
- **Не є кейлоггером**: не ведеться історія натискань клавіш, звичайний набір тексту не зчитується і не зберігається.
- **Відсутність історії тексту**: ні введений, ні перетворений текст не зберігається у базі даних чи на диску.
- **Відсутність збереження історії буфера обміну**: застосунок не створює власної історії буфера.
- **Безпека релізних збірок**: у робочій версії файловий лог на диск повністю вимкнений.

---

## Простими словами (Головне для користувача)

Якщо описати все без складних технічних термінів:

* **Працює лише тоді, коли ви просите**: FreePunto спить і взагалі нічого не робить, поки ви самі не натиснете гарячу клавішу (наприклад, одиночний `Control`).
* **Звичайний сценарій (взяв — змінив — забув)**:
  1. Ви натискаєте гарячу клавішу.
  2. Застосунок дивиться на виділений текст або на останнє слово перед курсором.
  3. Миттєво перемикає розкладку в оперативній пам'яті комп'ютера.
  4. Замінює текст на правильний.
  5. **Одразу назавжди забуває цей текст**.
* **Повний офлайн**: у застосунку взагалі немає коду для виходу в інтернет. Він фізично не вміє нічого нікуди надсилати.
* **Не стежить за клавіатурою**: застосунок не запам'ятовує, що ви друкуєте, не записує паролі, чати чи документи. Він реагує тільки на гарячі клавіші.
* **Паролі захищені**: якщо курсор знаходиться в полі введення пароля (захищеному крапками/зірочками), програма автоматично блокує операцію, нічого не зчитує і нічого не міняє.
* **Ніяких файлів на диску**: звичайна робоча версія не створює і не веде на вашому Mac жодних журналів чи файлів з логами.
* **Турбота про буфер обміну**: якщо для заміни тексту довелося використати буфер обміну, програма одразу повертає на місце те, що ви копіювали раніше (наприклад, скопійоване посилання чи номер картки), і ховає перетворене слово від менеджерів буфера обміну.

## 1. Логування та запис на диск

### Робоча (релізна) версія
* **Файловий лог вимкнено**: у робочій збірці посилання на файл логу `customLogFile == nil`. Файл логу (`/tmp/freepunto_debug.log`) **не створюється і запис на диск не здійснюється**.
* **Відсутність `print()`**: у всьому продакшн-коді (`Sources/PuntoApp` та `Sources/PuntoCore`) повністю відсутні виклики `print()`. Усі тестові виклики ізольовані у тестових раннерах.

### Налагоджувальні та тестові збірки
* Запис у файл `/tmp/freepunto_debug.log` активується **виключно** якщо:
  1. Збірка скомпільована у режимі налагодження (`#if DEBUG`), **або**
  2. В `Info.plist` прапорець `FreePuntoIsTestBuild == true` (тестові DMG/збірки для QA), **або**
  3. У системі явно задано змінну середовища `FREEPUNTO_LOG_FILE`.

### Системний лог macOS (`os.Logger`)
Для системної діагностики використовується підсистема `com.freepunto.FreePunto` (категорія `Diagnostics`) із прапорцем `privacy: .private`:
* **Що записується**: виключно службові технічні метадані:
  - факт запуску чи зміни налаштувань (`app_launch`, `hotkey_registered`);
  - тип доступного інтерфейсного елемента (`role=AXTextArea`);
  - кількість символів фрагмента (`characters=5`);
  - технічний результат операції (`outcome=successVerified` або `outcome=failed`).
* **Що суворо заборонено логувати**:
  - введений або виділений текст користувача;
  - результат перетворення або мову вхідного тексту;
  - вміст буфера обміну;
  - паролі або персональні ідентифікатори.

## 2. Повна мережева ізоляція (Offline Only)

* Додаток не імпортує і не використовує мережеві бібліотеки (`URLSession`, `Network.framework`, BSD sockets тощо).
* Додаток не виконує DNS-запитів, HTTP/HTTPS-запитів і не зв'язується з жодними серверами.
* Оновлення версій здійснюються прозоро та вручну через офіційні релізи GitHub.

## 3. Захист полів введення паролів

* У модулі [TextIOController.swift](file:///Users/VedicV/Documents/GitHub/Punto/Sources/PuntoApp/TextIOController.swift) впроваджено обов'язковий фільтр перевірки елементів:
  ```swift
  if let role = stringAttribute(kAXRoleAttribute, from: element), role == kAXSecureTextFieldSubrole {
      return false
  }
  if stringAttribute(kAXSubroleAttribute, from: element) == kAXSecureTextFieldSubrole {
      return false
  }
  ```
* Якщо поточний фокусний елемент є захищеним полем пароля (`AXSecureTextField`), FreePunto **негайно відхиляє операцію**: текст пароля не читається, не копіюється і не змінюється.

## 4. Захист буфера обміну (Clipboard Isolation)

Коли для читання або заміни тексту у складних інтерфейсах (наприклад, термінали, окремі веб-поля) використовується системний буфер обміну:
1. **Збереження стану**: перед операцією `ClipboardSession` фіксує попередній вміст буфера та системний `changeCount`.
2. **Відновлення стану**: після відправлення вставки старий вміст буфера обміну гарантовано відновлюється у блоці `defer`.
3. **Захист від менеджерів буфера обміну**: під час тимчасового запису додаються системні типи:
   - `org.nspasteboard.TransientType`
   - `org.nspasteboard.ConcealedType`
   
   Завдяки цим маркерам сторонні менеджери історії буфера обміну (Raycast, Paste, Maccy, Alfred тощо) ігнорують транзитний текст FreePunto і не зберігають його в історії.

## 5. Перехоплення клавіатурних подій (Event Tap)

* [HotKeyController.swift](file:///Users/VedicV/Documents/GitHub/Punto/Sources/PuntoApp/HotKeyController.swift) використовує `CGEventTap` виключно для відстеження:
  - подій зміни прапорців модифікаторів (для розпізнавання одиночного натискання `Control`);
  - натискання зареєстрованої комбінації клавіш.
* Застосунок **не реєструє і не слухає звичайні натискання символьних клавіш** під час набору тексту.
* Усі синтетичні клавіатурні події маркуються спеціальним числом `freePuntoSyntheticEventMarker` (`0x4652_5045`), що виключає зациклення або перехоплення власних сигналів.

## 6. Дозволи macOS (TCC: Accessibility)

Для взаємодії з активним текстовим полем іншої програми застосунку потрібен дозвіл macOS **Accessibility (Універсальний доступ)**:
* Дозвіл використовується виключно для взаємодії з Accessibility API (`AXUIElement`) під час натискання гарячої клавіші.
* За відсутності дозволу застосунок не робить спроб обійти обмеження macOS і пропонує користувачеві надати доступ через системне вікно налаштувань.
